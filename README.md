## 📖 Description

This repository contains a series of machine learning assignments designed to build a solid foundation in supervised and unsupervised learning techniques using Python. Each assignment focuses on core ML concepts with practical implementation using libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn.

### ✨ Key Highlights

- **Assignment 1** – *Data Preprocessing*  
  Covers cleaning, normalization, label encoding, and preparing data for ML models.

- **Assignment 2** – *Linear Regression*  
  Implementation of simple and multiple linear regression models with evaluation using MSE, RMSE, and R² score.

- **Assignment 3** – *Logistic Regression*  
  Used for binary classification problems. Evaluates models using accuracy, precision, recall, and F1-score.

- **Assignment 4** – *Support Vector Machine (SVM)*  
  Applies Linear and Kernel SVMs to datasets. Includes decision boundary plotting and parameter tuning using `C` and `gamma`.

- **Assignment 5** – *Decision Trees & Random Forest*  
  Tree-based classifiers for both classification and regression tasks. Includes feature importance analysis.

- **Assignment 6** – *Clustering Algorithms*  
  Focuses on unsupervised learning methods like K-Means and DBSCAN. Visualization of cluster boundaries and silhouette scores.

- **Assignment 7** – *Dimensionality Reduction*  
  Introduces PCA and LDA to reduce feature space while retaining variance. Includes 2D visualization of reduced components.
